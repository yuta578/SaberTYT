Estructura de las 8 Entidades del Modelo Relacional

Tablas normalizadas con tipado estricto, índices y claves foráneas.

8 Tablas / Normalizado 3FN
1. categorias 0..N preguntas
PK: id (BIGINT AUTO_INCREMENT)
• nombre (VARCHAR(120) NOT NULL)
• descripcion (TEXT NULL)
• activo (BOOLEAN DEFAULT TRUE)
• created_at / updated_at (TIMESTAMP)
2. preguntas Banco de Ítems
PK: id (BIGINT AUTO_INCREMENT)
FK: categoria_id → categorias(id)
• tipo (VARCHAR(20) [MULTIPLE, V/F])
• texto_base (TEXT NULL)
• enunciado (TEXT NOT NULL)
• retroalimentacion (TEXT NULL)
• puntaje_base (DECIMAL(5,2) DEFAULT 1.00)
• activo (BOOLEAN DEFAULT TRUE)
3. opciones_respuesta 2..4 por pregunta
PK: id (BIGINT AUTO_INCREMENT)
FK: pregunta_id → preguntas(id)
• letra (CHAR(1) ['A','B','C','D'])
• texto (TEXT NOT NULL)
• es_correcta (BOOLEAN DEFAULT FALSE)
4. cuestionarios Evaluaciones
PK: id (BIGINT AUTO_INCREMENT)
• nombre (VARCHAR(150) NOT NULL)
• descripcion (TEXT NULL)
• fecha_apertura (DATETIME NOT NULL)
• fecha_cierre (DATETIME NOT NULL)
• tiempo_limite_minutos (INT NOT NULL)
• intentos_permitidos (INT NOT NULL)
• calificacion_maxima (DECIMAL(5,2))
• calificacion_aprobacion (DECIMAL(5,2))
• mezclar_preguntas / mezclar_respuestas
• estado (VARCHAR(20))
5. cuestionario_preguntas Relación N:M
PK: id (BIGINT AUTO_INCREMENT)
FK: cuestionario_id → cuestionarios(id)
FK: pregunta_id → preguntas(id)
• orden (INT NOT NULL DEFAULT 1)
• puntaje_ponderado (DECIMAL(5,2))
UNIQUE(cuestionario_id, pregunta_id)
6. importaciones Auditoría Excel
PK: id (BIGINT AUTO_INCREMENT)
• nombre_archivo (VARCHAR(255))
• fecha_carga (DATETIME NOT NULL)
• total_filas (INT DEFAULT 0)
• total_validas (INT DEFAULT 0)
• total_errores (INT DEFAULT 0)
• detalle_log (TEXT NULL)
7. intentos Sesión de Examen
PK: id (BIGINT AUTO_INCREMENT)
FK: cuestionario_id → cuestionarios(id)
• nombre_estudiante (VARCHAR(120))
• codigo_estudiante (VARCHAR(30))
• numero_intento (INT DEFAULT 1)
• fecha_inicio (DATETIME NOT NULL)
• fecha_fin (DATETIME NULL)
• calificacion_final (DECIMAL(5,2))
• estado (VARCHAR(20))
8. respuestas_intento Persistencia Atómica
PK: id (BIGINT AUTO_INCREMENT)
FK: intento_id → intentos(id)
FK: pregunta_id → preguntas(id)
FK: opcion_seleccionada_id → opciones(id) [NULL = Omisión]
• es_correcta (BOOLEAN DEFAULT FALSE)
• puntaje_asignado (DECIMAL(5,2))
• marcada_revision (BOOLEAN DEFAULT FALSE)
UNIQUE(intento_id, pregunta_id)

Reglas de Negocio e Integridad Estructural

Restricciones activas en la base de datos y la capa de lógica

Regla Denominación Descripción e Implementación en Base de Datos & Backend Nivel de Validación
Temporalidad Ventana Temporal Coherente La fecha de cierre debe ser estrictamente posterior a la fecha de apertura (fecha_cierre > fecha_apertura). CHECK / Backend
Escala Escala de Evaluación Positiva La calificación máxima debe ser un valor numérico estrictamente mayor a cero (calificacion_maxima > 0). CHECK / Backend
Aprobación Umbral de Aprobación Válido La calificación de aprobación debe ser ≥ 0 y no puede superar la calificación máxima configurada. CHECK / Backend
Unicidad Clave Única de Respuesta Toda pregunta registrada debe tener exactamente una opción configurada como correcta (es_correcta = TRUE). Lógica / Importador
Alternativas Estructura Mínima de Opciones Preguntas de selección múltiple contienen 4 opciones (A, B, C, D) y las de Falso/Verdadero exactamente 2 opciones. Lógica / UI
Control Control de Intentos Permitidos El estudiante no podrá iniciar un nuevo intento si la cantidad de intentos realizados supera la cota permitida. Control de Acceso
Tiempo Cronómetro y Disponibilidad Un intento solo puede iniciarse dentro del rango de disponibilidad y se controla mediante temporizador en vivo. Temporizador JS
Omisiones Soporte de Preguntas Omitidas Preguntas no contestadas se registran formalmente con opcion_seleccionada_id = NULL y 0.00 pts. Persistencia Atómica
Revisión Marcado para Revisión El estudiante puede alternar la bandera de revisión durante la sesión sin alterar la calificación final. UI Interactiva
Inmutabilidad Inmutabilidad de Resultados Una vez finalizado el intento y calculada la calificación final escalada, los registros no pueden ser modificados. Inmutable
